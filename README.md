## WEB_HW2
This folder contains an **n8n automation** that generates a **designed HTML travel guide** for a destination from **Google Sheets**, sends it by email for **Approve/Reject**, and on approval **uploads the HTML page to GitHub** and updates the **HtmlLink** column in the sheet. It also includes a **GitHub backup** of the workflow JSON.
